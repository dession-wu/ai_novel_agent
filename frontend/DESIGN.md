# 故事工坊设计规范

面向中文小说作者。核心任务是建立作品、组织章节、持续写作；AI 是按需调用的协作工具。

## 参考与方向

2026-11-03 在 Variant 生成六个方案，采用 Ink Story Workshop 1 的居中标题、暖白纸面和三栏写作预览方向：https://variant.com/chat/e0d84ff1-b556-4340-b42f-a209849d9422 。按真实功能修正示例中的虚构用户数、过度承诺和空链接。参考为视觉方向，非照搬完整产品。

## 视觉规则

- 背景 #FAF9F6；正文 #292823；次要文字 #75736C；边界 #E6E3DC；主要操作 #935538。
- 阅读正文、文学标题用本地宋体回退；界面控件使用 Segoe UI / Microsoft YaHei。不依赖外部字体请求。
- 首页标题桌面 44px 左右，移动 29px；正文 14–15px；辅助说明 11–12px。长文行高约 2。
- 桌面内容宽 1180px，移动边距 18px；常用间距 8/12/16/24/32/48。
- 按钮 42–48px，圆角 5–6px；主要面板圆角 8px，细边界；只有预览使用轻阴影。
- 页头统一现有书本与笔图标和「故事工坊」名称。避免额外英文编号、纹理、渐变、发光和浮动印章。

## 页面与状态

- 首页：一句话说明用途、开始写作入口、可切换章节的交互示例、三项真实能力。示例明确标注，不伪装用户数据。
- 登录/注册：统一页头、纸白表单、明确字段标签、密码显示切换（登录）、提交中禁用和失败反馈。保留注册成功后登录的原流程。
- 工作台：暖白主题、陶棕操作色、弱化阴影，主内容占据主要空间。概览展示真实作品和继续写作入口，API 失败不回退虚构作品。
- 保持深色模式功能，使用对应暖灰背景和可读文本；不修改其他产品样式。
- 窄屏首页目录改横向选择、预览隐藏辅助栏；身份页改单列；桌面尽量保持短句完整，手机自然换行。
- 所有控件可键盘操作，显示 focus；章节示例支持上下方向键。错误显示可重试，空书架提供开始写作入口。

## 验收

检查首页、登录和注册、概览与编辑入口；桌面/窄屏检查溢出和可读性。保持原账户、数据隔离、章节保存和 AI Key 配置行为。
